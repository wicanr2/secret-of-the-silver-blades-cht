## 2. 原版證據

輸入：`START.EXE`（`b6c08c3b…`）、`GAME.OVR`（`9b01e970…`），資料段 `DS=0EF2`（線性 `EF20`）。反組譯以 capstone 5.0.3 讀原版檔。

| 用途 | 本作 | 幽靈騎士 | 證據 | 等級 |
|---|---|---|---|---|
| 選單逾時 | `DS:8A63..8A66` | `C0FA..C0FD` | `START.EXE` 0x3B9 `mov word [8A63],3000`、0x5AF 設 1000；`[8A67]=0x44`（`'D'`）為逾時預設；選單後清 0 | 已證實（反組譯、收據擋下寫入） |
| 選單結果與 demo 旗標 | `[59A2]`、`[67E9]` | `[84B2]`、`[8C50]` | 0x451 `cmp [59A2],'D' / jne / mov [67E9],1` | 已證實（反組譯） |
| 遊戲本體呼叫 | 簽章 +0x116（0x567 `lcall 0050:0025`），返回 +0x11B | 簽章 +0xA9，返回 +0xAE | 呼叫後接 `lcall 00A1:002A` 收尾、再判斷 `[67E9]`，與幽靈騎士配置相同；本作返回點是 `cmp`，不是遠呼叫 | 已證實（執行期記憶體 `135F` 起） |
| ECL 停止旗標 | `DS:59B4` | `84B4` | `GAME.OVR` 0x47FD 的 ECL 迴圈每圈檢查 `[59B4]`、`[67F5]`，進入（0x480F）與結束（0x485C）都清 0 | 已證實（反組譯、收據） |
| 戰鬥雙方存活數 | `DS:87CC..87CD` | `BE68..BE69` | `GAME.OVR` 0x3AC6D 起歸零重算；0xC445 起與 `[67E9]` 一起判斷戰鬥結束 | 強推論（反組譯同構；收據戰鬥中止成功） |
