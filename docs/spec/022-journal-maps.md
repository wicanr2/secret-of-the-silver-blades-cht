# 022 手札地圖則的圖面

狀態：READY（2026-10-23）。Issue：[#8](https://github.com/wicanr2/secret-of-the-silver-blades-cht/issues/8)。
補規格 007（手札面板，沿用克萊恩英豪）沒有涵蓋的部分：克萊恩英豪的手札沒有地圖則。

## 1. 需求

使用者要求（2026-10-22）：修正後的手札放進遊戲，玩家不必再查說明書。本作手札有 12 則是地圖
（第 1、32、35、36、38、41、45、49、52、66、68、72 則），正文只有一句「本則為地圖，見原版英文手札第 N 頁」，
要把圖面放進手札面板。

## 2. 來源

| 項目 | 內容 |
|---|---|
| 圖面 | 英文手札 `ssb-journal.pdf`（docs/re/002，mocagh）第 16–24 頁，`pdftoppm -r 300` 轉成 `workplace/journal/en-300/p-NN.png`（雙頁跨頁，3212×2478） |
| 標籤與裁切 | `text/journal-maps.zh-TW.tsv`：每則一列 `crop`（頁面座標）、`keybox`（原圖例框）、`key`（圖例標籤）、`label`／`vlabel`（圖上橫書、直書標籤）與譯文。只有座標與中文，不含原圖像素 |
| 譯名 | 依 `text/glossary.tsv`（新維地格里城、黑圈幫、知識之井、紅龍）與第 35 則標題（Toom 依標題譯「房間」）；圖例用語統一為牆、門、拱門、暗門、牢門、上樓梯、下樓梯、無法通行 |

珍056 下冊的地圖已有中文標籤，但掃描品質較差，圖面改用英文手札，標籤另行譯過。

## 3. 產生（`tools/journal_maps.py`，sosb-img 容器）

1. 裁出地圖，只留深藍墨線：亮度 < 165 且 R−B < 40，去掉紅色標題與背面透字；11×11 視窗墨點少於 12 的孤立點去掉。
2. 抹掉英文標籤與原圖例框（圖例框外擴 12 點，含外框線）。
3. 圖例改列在右欄：每個圖示取標籤正上方最高的一段連續墨線，排除上一列標籤與圖例外框。
4. 縮小前依縮放比加粗線條（MinFilter，縮小後約 2 點寬）；高瘦的地圖縮進一頁比例小於 0.42 時切成 2–3 段，上下重疊 60 點。
5. 中文標籤以源泉圓體 Medium 22 點畫回原位（紙色描邊），直書標籤一字一列。

輸出 `NN-K.png`，912×504（3 倍的 304×168 邏輯點）。圖檔由原版手札衍生，放 `workplace/journal/maps/zh-TW/`，不進 Git。

## 4. 面板契約（dosgolem `apps/sosb/journal.go`）

| 項目 | 定案 |
|---|---|
| 載入 | `LoadJournalMaps(dir)` 讀 `NN-K.png`，尺寸必須是 912×504；目錄不存在回空表 |
| 地圖則 | 有圖的手札只顯示圖頁，每張圖一頁，不顯示「本則為地圖」那句；沒有圖時照舊顯示正文 |
| 版面 | 地圖頁用邏輯像素 [8,312)×[8,192)：第 0 列標題（同文字頁）、[8,312)×[16,184) 圖面、第 184 列頁碼（多頁時） |
| 縮放 | 3 倍直接貼；其他倍率以面積平均縮放到 304×168×倍率 |
| 操作 | 翻頁、上下則、自動彈出與關閉都和文字頁相同（規格 007） |
| 前端 | `sosb-play -journal-maps <目錄>`；沒有指定時不載入 |

## 5. 驗收

1. 單元測試：有圖的手札頁數等於圖數、地圖頁的面板範圍與縮放、目錄不存在回空表、尺寸不符報錯。
2. 收據：手札面板預覽第 1 則兩頁、第 32 則一頁的 2 倍截圖，目視標籤與圖例。
