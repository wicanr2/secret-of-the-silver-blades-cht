# 020 切換列字級

狀態：CONFORMED（2026-10-22，§4 通過）。Issue：[#15](https://github.com/wicanr2/secret-of-the-silver-blades-cht/issues/15)。

## 1. 需求

使用者要求（2026-10-22）：工具列文字可以調整字型大小。使用者選定：

| 項目 | 定案 |
|---|---|
| 段數 | 小、中、大，切換列「字級」項（顯示「字中」）下拉選擇，記住上次選擇（偏好檔 `sosb-barfont.txt`） |
| 字模邊長 | 3 倍：小 16、中 22、大 24 像素；2 倍：小 12、中與大 16 像素 |
| 範圍 | 只影響切換列與它的下拉選單，不影響遊戲內文字與手札、攻略、地圖面板 |

## 2. 契約

- 格子仍是 8 邏輯像素一格，字模 1:1 置中畫在格內；項目位置與點擊範圍不隨字級改變。
- 字模：16 為 `-font`，24 為其 3 倍字模；12、22 由 `tools/font-dev.sh` 以源泉圓體 Medium／Bold 直接渲染
  `<字型>-bar12.golemfnt`、`-bar22.golemfnt`（字集只收 `text/host-text.zh-TW.tsv`）。缺檔時以最近鄰從相鄰字模縮放。
- 半形組合字（規格 005 §2）同樣補在 12、22 字模（`AddHalfWidthPairs` 放寬為寬度不必是 8 的倍數）。
- 旗標 `-barfont 1|2|3`；腳本動作 `barfont=n`、`barfonts`。
- 速度與字級下拉選單碰到右緣時往左移，不超出 320 邏輯像素。

- 發行相依：`sosb-rounded-bar12.golemfnt`、`-bar22.golemfnt` 要進發行包（規格 012），找字型時與主字型一起找；缺檔時退回最近鄰縮放。

## 3. 不做

- 不改遊戲內覆繪字型與面板字級。

## 4. 驗收

1. 單元測試：字級對應邊長、偏好檔、選單點擊、腳本動作、版面最寬組合放得下。通過。
2. 切換列收據 `tools/g14-toolbar-receipt.sh`：2 倍小、中、大與 3 倍小、中、大的切換列，字級與速度下拉選單展開。
   2026-10-22 六組通過目視：字級三段在兩種倍率下大小不同、項目位置不變；字級選單第三列「大」青色；
   選單碰到右緣往左移。截圖在 `workplace/probe/g14-toolbar-receipt/`。
