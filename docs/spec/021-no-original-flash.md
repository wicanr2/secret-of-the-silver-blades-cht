# 021 不露原版：譯文與 HD 圖的呈現順序

狀態：READY（文字與 HD 三個階段皆已抽樣量測：標題流程、進金庫、demo 戰鬥與 3D、鎮上 3D）。Issue：[#16](https://github.com/wicanr2/secret-of-the-silver-blades-cht/issues/16)。
取代 [docs/re/010](../re/010-flicker.md) 的「降低」目標；010 的量測與兩項修正仍有效。

## 1. 需求

使用者要求（2026-10-22）：

- 完全解決「先顯示原版字、才換成中文或其他語言」的閃爍，所有語言都適用。
- HD 模式下不能先顯示原版圖、才換成 HD 圖。
- 必要時可以修改原版 EXE 配合（只改記憶體，不改磁碟上的原版檔、不散布修改後的 EXE）。

## 2. 閃現的定義

以原版 8×8 像素為一格。比對每一畫格的呈現畫面與同一畫格的原版畫面（原版色號放大後的 RGB）：

- 「原樣呈現」：這格原版有墨跡（兩種以上色號），而且呈現畫面的這格每個像素都與原版相同。
- 「被改」：這格呈現畫面至少一個像素與原版不同（疊字、HD 圖）。

某格在第 f 格原樣呈現、在第 f' 格被改，`f < f' ≤ f + 8`，而且兩格的原版內容（8×8 色號）相同，記一次閃現。
原版內容相同這個條件排除動畫與換畫面；8 格的窗排除很久以前顯示過的同樣內容。
手札、攻略、地圖面板與切換列不列入比對（它們是玩家開的面板，不是對原版內容的替換）。

真的不翻譯的原版字（數字、沒有譯文的詞）一直原樣呈現、不會被改，不算閃現。

## 3. 量尺

dosgolem `xlate.FlashAudit`（dosgolem 規格 202 §2.6）。sosb-play 旗標 `-flash-audit` 在自動模式每格以疊字與 HD 合成一次（不含面板），
結束時印 `sosb-play: 閃現 N 次`，並列出前 60 行（同一對畫格、同一列的格子併一行：原樣呈現與被換的畫格、列、欄）。

## 4. 做法

原則：每一格會被譯文蓋住的地方，在任何一格呈現之前就要先被蓋住（譯文或背景色）。攔截點都在印字呼叫的進入點，
比像素早，進入點就能決定的文字本來就符合；要處理的是「進入點之後才決定」的地方。

| 路徑 | 進入點後才決定的原因 | 做法 | 狀態 |
|---|---|---|---|
| 還原顯存 | 原版不經印字常式，把同一段原文整塊還原回畫面（demo 戰鬥訊息區，第 4535、5047 格）；sosb 偵測到呼叫外的寫入就移除路徑 B 疊字 | 殘影疊字（dosgolem 規格 202 §2.7）：原版墨跡與某筆疊字顯示時完全相同，就照畫那筆譯文；sosb 自管的疊字（Frozen）以每幀畫面記指紋 | 已實作，量尺 0 |
| B | 疊字由 sosb 自管（Frozen），建立時就是 `Shown` | 另標 `Early`，顏色來自呼叫參數 | 已實作 |
| A | 綁定後第一次畫格事件前色盤還沒更新（docs/re/010 限制） | 量尺未量到；量到再處理 | 觀察中 |
| C | 逐字呼叫，整列印完才查得到詞 | 先蓋背景色、穩定一格才放行（docs/re/010）；量尺未量到「穩定一格後才查到」的情況 | 觀察中 |
| HD | 整塊吻合才換圖；原版改動一小塊就整張撤下；新圖分幾格畫完時前幾格露原版 | §4.1 | 已實作，標題流程量尺 0 |

### 4.1 HD

dosgolem 規格 204 §6、202 §2.8、§2.9（`a6e0254`）：

- 固定圖面（`Sticky`）：主題圖整張吻合啟用後，原版改動其中一部分時只遮被改的格，其餘維持 HD；墨跡格全部不吻合才撤下；
  另一張圖整張吻合時取代重疊的舊圖。
- 保留呈現（`Hold`）：某格內容等於某張主題圖在同一位置的墨跡格（原版正在畫一張已知的圖），換圖前直接畫那張圖這一格的 HD；
  同一位置同樣內容對到多張不同 HD 時改為保留上一幀，上限 60 幀。只作用在已知圖的格子，原版動畫與其他內容不受影響。
- HD 鎖存（`Latch`，202 §2.9）：戰鬥等圖層整件比對，一件被蓋到一小塊就整件退回；原版內容與色盤沒變的格沿用上次的 HD。

量測：冷開機標題流程（SSI 片頭 → 背景 → Forgotten Realms 字樣 → 本作字樣），3 倍＋HD 主題 7 項。

| 版本 | 閃現 | 原因 |
|---|---|---|
| 接入前的圖面規則 | 906 格 | 第 2132 格字樣畫一半時背景整張撤下 |
| 加固定圖面、保留上限 8 幀 | 316 格 | 第 196、497 格新畫面第一次出現，背景畫了 10 幀以上才整張吻合 |
| 保留上限 60 幀 | 0 | |

修改原版程式（例如在逐字程序不畫墨跡）先不做：疊字失效的判斷（dosgolem 規格 202 §2.3 錨定格、逐格指紋）靠原版墨跡還在畫面上，
墨跡沒了會讓殘字變多。量尺顯示覆繪層處理不了時再評估，屆時另寫規格。

## 6. 驗收

1. 單元測試：`FlashAudit` 的定義（原樣呈現後被改記一次、內容不同不記、超過窗不記、沒有墨跡不記）；殘影疊字
   （移除後同一幀照畫、原文回來才畫、只有非錨定格相同不畫、Frozen 疊字、`ForgetGhosts`、保留期限）。面板不列入由
   `Live.AuditFlash` 在面板前比對保證。
2. 收據以 `-flash-audit` 跑下列路徑，閃現都是 0：手札路徑（冷開機到新維地格里城）、開場 demo（訊息、3D 行走、戰鬥）、
   鎮上走到金庫、神殿、武器店。
3. HD：G9 主題出來後，同一組路徑以 3 倍＋HD 跑，閃現 0。
