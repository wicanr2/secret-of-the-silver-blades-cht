# 010 先畫英文再疊中文的閃爍

日期：2026-10-22。Issue：[#16](https://github.com/wicanr2/secret-of-the-silver-blades-cht/issues/16)。

使用者要求：必要時修改原版 EXE 配合多語系顯示，降低先繪製原版文字、再疊多語系文字的閃爍。
本輪以覆繪層處理，量測後確認這條路徑上不必修改原版程式。

## 量測

`tools/g16-flicker-probe.sh`：sosb-play 自動模式走手札收據的路徑（讀預建隊伍 → 查驗題 → 開場 → 鎮長對白 → 新維地格里城），
第 7500 到 15000 格逐格截圖（覆繪後畫面），`tools/g16_flicker_scan.py` 找「連續兩格同一區域都在變」的畫格，再抽命中處看。

| 位置 | 修正前 | 原因 | 等級 |
|---|---|---|---|
| 隊員名單重畫（第 14655 格） | 整份名單露出一格英文（NAME、AC、HP、GUY DE VALOIS…） | 新疊字整個蓋住舊疊字時舊的立刻移除，新的要等原版印完、下一次定色才顯示（dosgolem 規格 202 §2.3） | 已證實 |
| 路徑 A 讀取提示（第 13408 格） | 露出一格「LOADING...PLEASE」 | 同上 | 已證實 |
| 路徑 C 底列提示（第 10084、11645 格） | 露出一格「PRESS <ENTER>/<RETURN> TO CONTIN」 | 畫格快照落在原版逐字印到一半，整句查不到譯文，照原版顯示 | 已證實 |
| 路徑 B 文字視窗（鎮長對白） | 沒有 | 片段出現時已是中文 | 已證實 |

## 修正

| 路徑 | 做法 | 位置 |
|---|---|---|
| A | 疊字加入時就用呼叫參數的背景、前景色號（查最近一幀色盤）畫，原版還在印英文時已蓋住；下一幀依畫面實測重新定色 | dosgolem xlate `Stamp.Early`（規格 202 §2.3.1）、`apps/sosb/patha.go` |
| C | 一列剛被改寫、某個詞查不到譯文時，這一幀先以背景色蓋住；下一幀這列沒有再變、仍查不到，才照原版顯示 | `apps/sosb/pathc.go` `PathC.blank` |

沒有修改原版程式或記憶體中的程式碼。真的沒有譯文的底列詞（目前路徑上沒有）會晚一格才出現。

## 修正後

同一路徑重跑：候選由 26 處降到 22 處，名單、讀取提示、12574 格的閃現消失；底列在中間那格是背景色，接著直接出現中文。
剩下的候選逐一看過：開場圖逐段畫出（第 7903–7910 格）、畫面轉換、隊員防護與生命力數字（原版數字，不翻譯）晚於名字出現，都不是英文閃現。

## 限制

- 路徑 A 提早顯示用的色盤由 `Live.Frame` 在綁定後更新；綁定後第一次畫格事件前加入的疊字會用全黑色盤畫一格。
- 路徑 C 暫蓋只蓋一格，原版若跨兩格以上才印完一句，第二格仍可能露出半句。
